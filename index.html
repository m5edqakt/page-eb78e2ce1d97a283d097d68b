品牌简介

肥猫云(FatCat)是面向个人与小团队的网络加速服务，核心能力是机场订阅：一次购买即可在 Clash、Shadowrocket、Surge 等客户端中使用同一套节点。服务定位为稳定的梯子与加速器，覆盖日常浏览、视频解锁与对延迟敏感的游戏线路。

节点侧以香港、日本、新加坡、美国、台湾等常用出口为主，旗舰与团队线路包含 IPLC 专线优化，降低跨境抖动。流量按月结算，设备数按套餐限制同时在线。官方身份以本站套餐说明、订阅发放与客户端指引为准，下载与更新请通过页面内「官网下载」锚点进入对应说明，避免来路不明的安装包。

与传统单机 VPN 不同，肥猫云强调「订阅 + 多客户端」：同一订阅可在手机、电脑之间切换，规则由客户端本地执行，便于按应用分流、绕过国内站点或指定流媒体走专线。

客户端选择

肥猫云不绑定单一 App，订阅兼容主流协议。请按系统选择客户端，再导入官网发放的订阅地址。以下为推荐组合，安装包请从各客户端项目或应用商店获取，配置以肥猫云订阅为准。

Windows

推荐 Clash Verge / Clash for Windows。导入订阅后开启系统代理，可按域名分流。适合办公与下载场景。

macOS

可用 ClashX.Meta 或 Surge。菜单栏一键切换节点，规则集支持流媒体走指定出口。

Android

推荐 Clash Meta for Android。后台稳定，支持分应用代理，避免国内 App 误走代理。

iOS / iPadOS

常用 Shadowrocket、Stash、Quantumult X。从 App Store 安装后粘贴订阅，开启 VPN 配置即可。

Linux / 路由器

Clash 内核或兼容订阅的软路由均可。团队版可配合定制路由，把游戏与会议单独走 IPLC。

使用场景

流媒体与资讯

旗舰版强调全节点原生解锁，适合需要稳定观看海外影视、直播与资讯站点的用户。基础版覆盖常见平台的基础解锁，高峰期可切换备用节点。

游戏与实时对战

IPLC 专线降低跨境丢包，适合对延迟敏感的对战与更新下载。建议游戏进程走游戏节点，其他流量走普通线路，避免抢带宽。

远程办公与协作

会议、代码仓库与云盘可指定代理。团队版支持更多同时在线设备与定制路由，方便工作室统一出口策略。

差旅与多设备

同一订阅在手机与电脑间切换。设备数按套餐计数，长期多终端请选择旗舰或团队。

操作说明

  1. 在官网选择套餐并完成支付，进入用户中心确认流量与到期时间。
  2. 复制机场订阅链接（通常为 Clash / 通用订阅）。不要把链接发到公开群组。
  3. 按上一节选择客户端并完成安装，授予 VPN 或系统代理权限。
  4. 在客户端选择「从 URL 更新」，粘贴订阅，等待节点列表刷新。
  5. 先测延迟再启用规则模式：国内直连、海外代理。流媒体可锁定对应区域节点。
  6. 若无法连接，检查系统时间、订阅是否过期、本地防火墙是否拦截内核。

节点与性能说明

普通池适合浏览与中等带宽；IPLC 与 VIP 池面向游戏和高并发。实际速度受本地宽带、时段与目标站影响。建议收藏 2–3 个低延迟节点作为常用，其余作备用。流量以用户中心统计为准，当月用尽后可能限速，可升级套餐或等待重置。

常见问题

肥猫云是机场还是 VPN？和普通加速器有何不同？

肥猫云以机场订阅为主，同时可在各系统客户端中作为 VPN 加速器使用。区别在于一份订阅可导入多个客户端，规则在本地执行，而不是只能使用单一封闭 App。

如何完成客户端下载并导入肥猫云订阅？

先从对应系统的正规渠道安装 Clash、Shadowrocket 等，再在肥猫云用户中心复制订阅 URL，于客户端内「订阅/配置」处更新。本站「客户端选择」与「官网下载」章节有平台对照。

三个套餐该怎么选？流量与设备不够怎么办？

个人轻度使用选基础版；需要原生流媒体与游戏线路选旗舰版；多成员或多设备选团队版。流量或设备不足时可升级，年付按页内标价执行。

是否支持流媒体解锁和游戏加速？

基础版提供基础流媒体解锁；旗舰版为全节点原生解锁并含 IPLC 游戏优化；团队版另有 VIP 高带宽节点。具体片名与区服仍受版权与线路波动影响，可换节点测试。

连接失败或速度慢时如何排查？

确认订阅未过期、客户端已更新配置、系统时间准确。尝试切换协议或节点，关闭占用 7890 等端口的旧内核。游戏请走专线节点并避免与大流量下载同时进行。

如何联系支持？团队版有什么额外服务？

旗舰版含 7x24 优先工单；团队版配备专属客户经理与定制路由沟通。工单请通过官网用户中心提交，并附上客户端类型、节点名称与错误截图文字描述。

合作展示：如需为企业线路或批量订阅沟通，请通过官网工单注明「商务合作」。本栏为文字合作位，不含第三方跳转脚本。
